1 The pitch — 30 seconds

Memorize this. Lead with the problem, not the stack.

“Compass is a parenting companion for the digital age. It helps parents of kids aged 2 to 8 with one problem: instead of doom-scrolling for advice, you get one small, concrete thing to try right now — personalized to your child and checked against real research. And it remembers your family, so the advice gets sharper the more you use it.”
Closer: “Every piece of advice comes with a ‘when to put the screen away’ note — that’s our principle: technology with intention.”

3 How it works inside

The three ideas that make it more than a ChatGPT wrapper. Master these and you own the Q&A.

a) Memory — “the soul of the product”

Each family has a persistent memory: the child profile + learnings (facts) + episodes (situation → suggestion → outcome). The coach reads it before every answer and writes back after. It’s hard-scoped by familyId — one family can never reach another’s data.

“It’s a typed, per-family memory. The coach reads it before every answer and writes back after — so guidance personalizes over time.”

b) The agentic Coach — a tool-loop, not a single call

Not one LLM call — a bounded tool-loop (up to 6 steps). Real tools: get_family_profile, retrieve_evidence, find_studies, record_learning / log_interaction. Every step is recorded into a trajectory shown in a “Behind the scenes” panel — visible proof it’s agentic and grounded.

“The coach runs a tool-loop: it reads the family profile, retrieves evidence, searches studies, then commits a single next step. Every step is recorded so you can see the reasoning.”

c) Evidence, not authority

Advice is checked against curated clinical studies + a live, quality-filtered search of Europe PMC (peer-reviewed only). Pasted/found content is treated as evidence to weigh, never as orders, and citations are validated against sources actually retrieved.

“The model can’t fabricate a citation — references are validated against sources actually retrieved.”

4 Key vocabulary

Pronounce these with ease — they’ll ask.

Agentic (a-JEN-tik)“The AI decides which tools to call and loops until it has an answer — it acts, not just responds.”
Tool-loop“The model calls real functions, gets results, calls again — bounded to 6 steps and a cost ceiling.”
RAG“Retrieval-Augmented Generation — it retrieves real evidence and grounds the answer in it.”
Grounded“The advice is backed by retrieved sources, not the model’s opinion.”
Multi-tenant“Many families share one database, but each is isolated — scoped by familyId.”
Provider-agnostic“One interface wraps both Gemini and OpenAI — I can swap or fall back.”
Ephemeral token“For voice, the API key never reaches the browser — the server mints a short-lived secret.”
COPPA-minded“Children’s privacy law — I store only a first name and an age band, never a birth date or photo.”
Data minimization“I collect the least data possible to do the job.”
OAuth 2.0“Standard ‘Sign in with Google’ — I built the Authorization Code flow without a library.”
Semantic vs. episodic“Semantic = durable facts (the profile). Episodic = events (situation → suggestion → outcome).”
Peer-reviewed“Research checked by other scientists before publishing — the only studies I trust.”

5 The demo flow

Tell a story: problem → magic → trust. Follow this order.

Before you start: open the app on localhost:3000 or the live link. Mention: “guests can use the whole app — no sign-up wall.”

  1. Landing page
    “This is the problem: parents drowning in conflicting advice online.”
  2. Onboarding (chat or voice)
    “It gets to know my child through a warm conversation — name, age band, temperament, what we’re working on. No forms.” If you dare, use voice here — it’s the wow.
  3. Coach — “Your one next step” (the heart — spend time here)
    Type something real: “bedtime is a battle.” → One concrete step appears.
    Open the “Behind the scenes” panel → “Here’s the proof it’s agentic: it read my profile, retrieved evidence, found studies, then committed one step — with the screen-away note.”
  4. Paste & personalize
    Paste a reel link or a screenshot. → “It reads text, links, even images via vision, checks them against evidence, and turns them into one step that fits my child — or tells me honestly when it’s not real parenting advice.”
  5. Help me now (voice)
    “An in-the-moment voice coach. It calms the parent first, then gives one tiny thing to try.”
  6. What Compass remembers
    “Full transparency. Everything stored, in plain language. One tap to add context or erase it all.”
  7. Close
    “Three principles: evidence, not authority · technology with intention · privacy by design.”
⚠️ Plan B: if the internet fails or voice won’t connect, have screenshots of every step ready. Voice depends on the network — don’t make it your only demo.

6 Questions they’ll ask

“Isn’t this just a ChatGPT wrapper?”

“No. Three things: an agentic tool-loop with real functions, grounded in peer-reviewed evidence with validated citations, and persistent per-family memory that personalizes over time.”

“How do you protect children’s privacy?”

“COPPA-minded: first name only, age band not birth date, never a photo or location. It supports the parent — it never monitors the child. Data is hard-scoped by familyId, and any family can erase everything in one tap.”

“What if the AI gives wrong advice?”

“It weighs evidence instead of asserting authority, refuses content that isn’t real parenting advice, and can’t fabricate citations — they’re validated against retrieved sources.”

“Why two LLM providers?”

“Resilience and flexibility. One interface, a health-check, and automatic fallback if one provider fails.”

“Where’s the data stored?”

“Google Cloud Firestore in production, using Application Default Credentials — no API keys in the code. A local JSON store for dev.”

“How does the live voice work?”

“OpenAI’s Realtime API over WebRTC. The server mints an ephemeral token so the API key never reaches the browser.”

7 Final tips

  • Practice the hard words out loud once: agentic, ephemeral, multi-tenant, peer-reviewed, COPPA, Firestore, Europe PMC.
  • Lead with the problem, not the stack. People remember “one small thing to try right now,” not “Next.js 16.”
  • If you blank out, return to the three principles: evidence not authority · technology with intention · privacy by design.
  • Keep the live link and screenshots as backup.
  • Strongest closing line: “It’s not about more screen time or less — it’s about technology with intention.”
